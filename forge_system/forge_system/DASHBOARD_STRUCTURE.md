# FORGE Dashboard Structure

## Visual Direction

- near-black base
- aggressive red accent
- glass surfaces
- high-contrast numbers
- command-center feel, not SaaS softness

## Primary Navigation

1. CEO Overview
2. Jarvis Command
3. Automations
4. CMO System
5. CTO System
6. Outreach Pipeline
7. CRM + Meetings
8. Landing Page Intelligence
9. Analytics
10. Content
11. Settings

## 1. CEO Overview

Purpose:

- one-screen company state

Widgets:

- current pipeline value
- weighted pipeline value
- active campaigns
- meetings booked this week
- top performing segment
- red alert strip for delivery or system failures
- daily execution priorities from Jarvis

## 2. Jarvis Command

Purpose:

- direct command interface to the whole company

Widgets:

- main Jarvis chat
- mode selector: strategy / operations / diagnostics
- morning briefing
- action approvals
- memory indicators
- recent Jarvis decisions

## 3. Automations

Purpose:

- define work that Jarvis or specialist systems run automatically

Widgets:

- automation task list
- task owner: Jarvis / CMO / CTO / Intel / Ops
- trigger type: manual / schedule / event
- priority
- approval-required switch
- run history
- failed run alerts

## 4. CMO System

Purpose:

- campaign thinking, messaging, and funnel improvement

Widgets:

- campaign thesis cards
- subject line test board
- segment ranking
- landing-page angle performance
- reply-rate diagnosis
- content opportunities

## 5. CTO System

Purpose:

- reliability and infrastructure oversight

Widgets:

- Supabase health
- Redis / queue health
- Gmail API status
- Gemini token usage state
- Apify source run status
- failed jobs and retries
- analytics root integrity panel

## 6. Outreach Pipeline

Purpose:

- source -> enrich -> draft -> review -> send -> reply

Widgets:

- source runs
- enrichment queue
- draft review queue
- approved queue
- send queue
- replies and booked meetings

## 7. CRM + Meetings

Purpose:

- turn outreach into trackable revenue movement

Widgets:

- all leads
- company records
- lifecycle status
- booked calls
- meeting notes
- conversion outcomes

## 8. Landing Page Intelligence

Purpose:

- measure what happens after the click

Widgets:

- page visits by campaign
- visitor companies
- chatbot engagement
- CTA clicks
- booked calls from page
- hottest proof block / segment

## 9. Analytics

Purpose:

- show what actually works

Widgets:

- reply rate by campaign
- meeting rate by segment
- best subject lines
- best message patterns
- best landing-page path
- signal roots and collection checkpoints

## 10. Content

Purpose:

- proof assets that feed both campaigns and landing pages

Widgets:

- case study queue
- offer proof snippets
- content angle board
- objection library
- best-performing claims

## 11. Settings

Purpose:

- configure all external systems

Widgets:

- Gemini
- Gmail
- Supabase
- Redis
- Apify
- Calendly / booking link
- Slack
- Notion
